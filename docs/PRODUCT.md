# Гипотеза продукта

«Бриф» для русскоязычных дизайн-, веб- и маркетинговых агентств из 2–10 человек. Узкая задача: не потерять клиентский запрос и получить решение по понятному предложению без аккаунта клиента.

Сегмент и проблема — гипотезы, не результат проведённого исследования. Новизна всей категории не заявляется: существуют CRM, клиентские порталы и сервисы предложений. Возможное преимущество — простой русскоязычный процесс и самостоятельное размещение. Его ценность ещё предстоит проверить. Оценка бизнеса в $10 млрд не прогнозируется.

## Проверка спроса без рекламного бюджета

1. После юридической и инфраструктурной готовности найти 10 агентств через собственные публичные страницы. Собирать сведения о компаниях, минимизировать данные физических лиц. В этом репозитории нет выдуманной базы контактов.
2. Использовать разрешённые площадкой публикации и ответы на явные запросы. Рекламные личные сообщения — только при документированном предварительном согласии. Не автоматизировать спам.
3. Предложить исследовательский разговор без обещания заработка: как сейчас принимают заявки, где теряются решения, сколько времени занимает согласование.
4. Пригласить 3 команды в пилот после настройки хранения и документов. Измерить число настоящих предложений, долю принятий, возврат на второй неделе и причины отказа. Не выдавать демо-события за метрики бизнеса.
5. Гипотеза оплаты: платное управляемое размещение/поддержка после валидации спроса. Цену определить по интервью и затратам, не обещать бесплатный облачный хостинг бессрочно.

## Что нужно для внешнего запуска

Российский сервер с постоянным диском и HTTPS; оператор и документы; процедуры безопасности/удаления; рабочий канал поддержки; инструменты размещения и разрешённые каналы продвижения. Инструменты этой сессии не предоставляют рекламного кабинета, почтового канала или управления production-хостингом. Никакие письма, рекламные объявления, продажи или оплаты не совершались. Для просмотра доступно отдельное статическое браузерное демо без серверной регистрации; это не production-размещение платформы.
