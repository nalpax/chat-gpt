# Проверка 2 ноября 2026

Текущая облачная среда, Node.js 24.19.0 / SQLite 3.53.3, Linux.

- `npm run check` — синтаксис сервера и клиента проверен.
- `npm test` — 5 тестов, все прошли. Проверены изоляция рабочих пространств, доступ без сессии, Origin, жизненный цикл предложения, отзыв ссылки, блокировка принятого предложения, регистрация/вход/выход, валидация, CSP, сохранение данных/сессии после перезапуска, отключение реальных аккаунтов в обычном режиме.
- Chromium через Playwright: главная → демо → новый проект → клиентская ссылка в отдельном браузерном контексте → принятие → заблокированные условия → выход. Ошибок JavaScript не получено. Проверены ширины 1440 и 390 px; горизонтального переполнения страницы на телефоне не обнаружено. Скриншоты — `artifacts/`.
- ffprobe: рекламный `marketing/promo.mp4`, 15.0 секунд, 1280×720, H.264; без звука.

Первый запуск HTTP-сервера в ограниченной песочнице получил EPERM. Тесты и браузерная проверка выполнены после разрешённого запуска с доступом к локальным сокетам. Первоначальный браузерный тест остановился на неоднозначном селекторе «Создать проект»; селектор уточнён до формы, полный сценарий затем прошёл.

Не проверены: публичный хостинг, TLS production, восстановление из резервной копии, масштабирование, нагрузка, доступность с ассистивными устройствами, актуальное юридическое соответствие, платёжный провайдер, реальная доставка сообщений, спрос/конверсия/выручка. Публикация и GitHub push фиксируются отдельно и не следуют из этого отчёта.
