# Бриф

Работающий MVP для небольших агентств: клиентские запросы → предложения → согласования. Самостоятельное размещение, Node.js 24+, встроенная SQLite, без npm-зависимостей, CDN, аналитики и платных API.

## Посмотреть без установки

[Открыть браузерное демо](https://raw.githack.com/nalpax/chat-gpt/main/docs/index.html) → «Посмотреть демо».

Это автономная демонстрация интерфейса, а не публично размещённый сервер. Только вымышленные данные; проекты сохраняются в localStorage текущего браузера. Клиентские ссылки работают только в этом же браузере: отправить их другому человеку как настоящее предложение нельзя. Регистрации, отправки писем и платежей в этой версии нет. Бесплатный сторонний просмотр не рассчитан на production или гарантированную доступность. Создание файла демо: `node scripts/build-demo.mjs`.

## Запуск

```sh
cd /workspace/chat-gpt
node --version # 24 или новее
npm run check
npm test
npm start
```

По умолчанию слушает `127.0.0.1:3000`. Проверка: `curl --fail http://127.0.0.1:3000/api/health`. Откройте приложение в браузере на машине, где оно запущено. Для внешнего размещения настройте HTTPS reverse proxy; не публикуйте встроенный сервер напрямую.

**По умолчанию регистрация и вход отключены.** Демо предназначено только для синтетических данных. Страна текущей среды не подтверждена. Не вводите реальные персональные данные. Публичный запуск и правовая готовность не подтверждены.

## Что работает

- Изолированное демо с шестью вымышленными проектами для каждой сессии.
- Создание, редактирование, удаление, поиск и фильтры проектов.
- Клиенты, суммы, сроки, история событий, CSV-экспорт с защитой от формул.
- Отдельная клиентская ссылка, принятие без аккаунта, фиксация времени.
- При редактировании старая ссылка отзывается. Принятые условия заблокированы.
- Регистрация и вход с хешированием паролей scrypt, сессиями HttpOnly и разделением рабочих пространств — доступны после осознанного включения.
- Адаптивный интерфейс, клавиатурные диалоги, локальное хранение на сервере.

Согласование по ссылке — фиксация решения владельца ссылки, **не подтверждение личности, не электронная подпись и не замена договору**. Любой обладатель ссылки может принять предложение; передавайте её только адресату. Проект со статусом «Согласован» не означает оплату. Денежные метрики — бюджеты, не выручка.

## Хранение и настройки

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `3000` | Порт |
| `HOST` | `127.0.0.1` | Интерфейс сервера |
| `DATA_DIR` | `./data` | Постоянный каталог базы |
| `COOKIE_SECURE` | выключено | `1` для Secure cookies при HTTPS |
| `ENABLE_REAL_ACCOUNTS` | выключено | `1` включает вход/регистрацию; только после условий из `docs/RUSSIA-LAUNCH.md` |

База создаётся автоматически. Не размещайте `data/` в публичном каталоге. Для простого согласованного бэкапа остановите сервер и скопируйте весь `DATA_DIR` на защищённое хранилище в согласованной юрисдикции; восстановление нужно отдельно проверить. Процессы после восстановления облачной среды запускаются заново.

## Границы версии 0.1

Это MVP, а не готовая к массовому коммерческому запуску система. Пока нет: приглашений сотрудников и ролей, восстановления/подтверждения email, MFA, документов конкретного оператора, автоматического срока удаления демо, пользовательского удаления аккаунта, резервного копирования по расписанию, биллинга, чеков, отправки email, юридически значимой подписи, загрузки файлов и интеграций. Демоданные остаются в локальной SQLite до ручного удаления оператором; сессии истекают через 7 дней. Для публичного демо сначала нужны TTL-очистка и защита от массового создания пространств. Лимит запросов действует на IP непосредственного соединения и сбрасывается при перезапуске; за reverse proxy это не полноценная защита от злоупотреблений.

Платежи и CRM-интеграции не имитируются. Внешних сообщений не отправлено, клиентская база не сформирована. Привязка платёжного провайдера сама по себе не устраняет перечисленные условия запуска.

`marketing/` — материалы для проверки спроса, `docs/` — стратегия и требования размещения в РФ, `artifacts/` — результаты браузерной проверки. Подтверждённого исследования рынка и доказательств спроса пока нет.
